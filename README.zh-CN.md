# 小丑牌内置调试菜单汉化

[English](README.md) | **简体中文**

**开启游戏自带的 Tab 调试菜单，隐藏黑色 LÖVE 控制台，并提供中文菜单补丁。**

[下载最新版](https://github.com/RyanLiu1208/balatro-debug-menu-zh/releases/latest) · [配置文件](conf.lua) · [菜单翻译表](translations.json)

本项目是配置文件和文字补丁。不需要 Lovely、Steamodded 或其他模组加载器。仓库不包含 Balatro.exe、完整游戏脚本、图片、存档或游戏资源。

## 1. 文件用途

| 文件 | 用途 |
| --- | --- |
| [`conf.lua`](conf.lua) | 开启内置调试功能，关闭黑色控制台；文件内有中英注释。**单独替换它不会汉化菜单。** |
| [`translations.json`](translations.json) | 调试菜单 27 条英文原文与中文译文的对照。 |
| [`patch.py`](patch.py) | 可选的本地补丁工具：将配置和汉化同时写进你自己的游戏 EXE，先备份再替换。 |
| [`tests/`](tests) | 使用模拟 EXE/ZIP 测试补丁，不需要游戏文件。 |

`conf.lua` 只控制启动配置。菜单按钮和说明位于游戏内部的 `functions/UI_definitions.lua`。完整中文菜单需要同时修改这两个文件。补丁工具只改配置和调试菜单文案，不改按钮回调。

## 2. 兼容性与准备

| 项目 | 说明 |
| --- | --- |
| 已实测版本 | Windows Steam 版 `1.0.1o-FULL`；已实际确认游戏启动和中文菜单显示。 |
| 其他版本 | 未逐一测试。英文文案变化时，自动补丁会拒绝继续，而不是盲目修改。 |
| 游戏语言 | 完整汉化后建议在游戏中选择简体中文，以使用中文字体。 |
| 操作前 | 保存并彻底退出游戏。备份整个原 EXE，以及 `%APPDATA%/Balatro` 中的存档。 |
| 更新覆盖 | Steam 更新、验证游戏文件或换回原 EXE，可能覆盖补丁。 |

这是调试功能：解锁与发现会改变收藏进度，部分按钮会直接改变牌局。先在备份或测试存档中熟悉操作。

## 3. 安装方式 A：手动替换 Lua

不需要 Python。此方式开启菜单并隐藏控制台，菜单默认仍是英文；需要中文时继续使用方式 B，或按第 5 节手动替换界面文案。

| 步骤 | 说明 |
| --- | --- |
| 1 | 在 GitHub 点击 **Code → Download ZIP**，解压本项目。 |
| 2 | Steam 游戏库 → 右键 Balatro → 管理 → 浏览本地文件，找到 `Balatro.exe`。 |
| 3 | 把原 `Balatro.exe` 复制为备份，放在另一位置。 |
| 4 | 用支持内嵌 ZIP 的压缩工具打开 `Balatro.exe` 的压缩包内容，找到根目录的 `conf.lua`。 |
| 5 | 将仓库中的 `conf.lua` 拖入压缩包，确认替换同名文件，并等待写入完成。不要放进额外的文件夹。 |
| 6 | 从 Steam 启动游戏，按住 **Tab** 查看菜单，松开关闭。 |

**不要把游戏全部解压后打成普通 ZIP，再改名为 EXE。** 游戏 EXE 前部还有启动程序，普通 ZIP 不能替代它。压缩工具如果无法正确写回内嵌压缩包，请改用方式 B。

## 4. 安装方式 B：同时应用配置和中文菜单

需要本机 Python 3.9 或更新版本，仅使用标准库，**无需 pip 安装任何依赖**。先解压本项目，再在项目目录运行下列命令。请将示例路径替换为你自己的游戏位置。

先检查兼容性，不修改游戏：

```powershell
python patch.py --exe "C:\Program Files (x86)\Steam\steamapps\common\Balatro\Balatro.exe" --check
```

确认游戏已经退出，再应用补丁：

```powershell
python patch.py --exe "C:\Program Files (x86)\Steam\steamapps\common\Balatro\Balatro.exe"
```

如果电脑使用 `py` 启动 Python，可以将命令开头的 `python` 换成 `py -3`。

成功时输出 `"modified": true`，并显示 `backup` 备份路径。备份位于游戏 EXE 旁边，名称形如 `Balatro.exe.before-debug-zh-时间戳.bak`。补丁会检查 ZIP 完整性、保留 EXE 启动部分，核对其他条目内容，然后替换。重复应用同一补丁会输出 `"already_applied": true`。

若出现权限错误，先确认游戏已完全退出且目标目录可写。失败时保留的 `.bak` 是恢复用的备份，不要当作游戏更新文件。

## 5. 菜单文案

这些字符串只属于调试菜单。手动汉化时，在 EXE 内的 `functions/UI_definitions.lua` 中找到 `create_UIBox_debug_tools()` 函数，只替换这个函数里的显示文案，保留引号、逗号、括号和回调名称。按 UTF-8 保存并替换回压缩包。自动方式已包含这一步。

全部 27 条菜单原文和译文见 [`translations.json`](translations.json)。

## 6. 实际操作

### 显示菜单

按住 **Tab** 显示菜单，松开关闭；需要点击菜单按钮时，保持 Tab 按住，再用鼠标点击。Tab 是显示帮助面板，数字键和 Q 的功能并不要求同时按住 Tab。

### 解锁、发现、生成

在收藏/卡牌展示菜单中，把鼠标停在目标卡牌上，再按数字键。不是只按键就随机送一张牌。

| 按键 | 说明 |
| --- | --- |
| **1 — 解锁** | 跳过这张牌的解锁条件，使其处于已解锁状态；不会直接加入当前牌局，也不自动标记为发现。 |
| **2 — 发现** | 先解锁，再标记为已发现，使收藏显示正常牌面与介绍；不会直接送到手中。 |
| **3 — 生成** | 将鼠标指向的小丑牌或消耗牌加入当前牌局；必须已有对应区域且有空位。消耗牌包括塔罗、星球、幻灵。此快捷键不生成普通扑克牌，也不自动做永久解锁。 |

例：想使用蓝图，先进入牌局，再在能够打开的收藏界面找到蓝图，鼠标悬停并按 **3**；小丑槽满了不会生成。想只补收藏进度，按 **2**，无需生成。

### 其他快捷键

| 按键 | 说明 |
| --- | --- |
| **Q** | 悬停小丑牌/扑克牌后，依次切换普通 → 闪箔 → 镭射 → 多彩 → 负片 → 普通。实际支持范围取决于被指向的卡牌。 |
| **H** | 隐藏/显示主要界面，观察背景；再次按可恢复。 |
| **J** | 切换开场动画显示，并离开当前牌局回到开场界面；不是无影响的预览按钮。 |
| **8** | 显示/隐藏鼠标指针。 |
| **9** | 切换额外提示显示状态。 |

开启 `_RELEASE_MODE = false` 也会启用游戏原本存在的其他调试快捷键。本项目不删除或改写它们；例如 **B 会重新开始牌局，L 会重载已保存牌局**，不要在正常游玩时随意试按。

### 菜单按钮

| 按钮 | 用途 |
| --- | --- |
| 金钱 +$10 | 当前牌局增加 $10。 |
| 轮次 +1 | 轮次计数加一；不是自动完整打完一个盲注。 |
| 底注 +1 | 底注计数加一；不是保证获得下一底注奖励。 |
| 出牌 +1 | 增加一次剩余出牌次数。 |
| 弃牌 +1 | 增加一次剩余弃牌次数。 |
| 重掷 Boss | 在有盲注选择界面的适用状态调用 Boss 重掷。 |
| 筹码 +10、倍率 +10、筹码 ×2、倍率 ×10 | 修改当前出牌计分面板数值，不等于直接修改本盲注累计分数；效果取决于结算时机。 |
| 重置筹码倍率 | 将当前出牌面板的筹码与倍率都设为零。 |
| 赢下本局 | 在牌局中触发获胜逻辑。 |
| 输掉本局 | 将当前牌局切换到失败状态。 |
| 切换背景 | 切换调试背景显示。 |
| 金宝显示 | 切换调试金宝角色的显示状态。 |
| 金宝说话 | 已显示调试金宝时，触发其对话动画。 |

## 7. 常见问题与恢复

| 问题 | 说明 |
| --- | --- |
| 仍出现黑色控制台 | 确认实际启动的 EXE 内 `conf.lua` 为 `t.console = false`，不是另一份游戏副本；完全退出后再启动。 |
| Tab 没反应 | 确认 EXE 根目录的配置包含 `_RELEASE_MODE = false`，游戏窗口已获得键盘焦点，且不是只把文件放在 EXE 旁边。 |
| 菜单仍是英文 | 单独替换配置不会汉化。应用方式 B，或按第 5 节修改界面脚本。 |
| 中文方块或不显示 | 切换游戏语言为简体中文，再重新打开菜单。 |
| 按 3 不生成 | 需要在有当前牌局区域的状态、菜单里悬停小丑牌或消耗牌，并确保对应槽位未满。 |
| 补丁提示不兼容 | 当前版本或其他修改改变了菜单文案。先恢复原版 EXE，再核对游戏版本；不要强行替换未知代码。 |
| 想完全还原 | 退出游戏，把备份的完整原 EXE 复制回 `Balatro.exe`；也可使用 Steam 的验证游戏文件功能恢复官方文件。 |

只把 `_RELEASE_MODE` 改为 `true` 会关闭调试快捷键，但不会撤销收藏解锁、发现或已经写入存档的变化；这些需恢复操作前的存档备份。
